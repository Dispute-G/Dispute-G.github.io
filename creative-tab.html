Креативная вкладка

Для собственного удобства или игроков, которые используют ваш мод, было бы неплохо иметь свою отдельную креативную вкладку. Её добавление крайне простое.

Создание класса

Для начала мы создадим отдельный класс под это. Помним - структурирование проекта!

В моём случае он будет по пути:

C:\Users\evi\Desktop\Minecraft Mods\My Learning\src\main\java\com\asrug\learning_mod\client\ModCreativeTabs.java

Познакомимся с двумя вариантами работы с креативной вкладкой.

Вариант 1: Добавление в существующую вкладку

Добавление нашего предмета в уже существующую вкладку в игре, допустим, в "Ингредиенты":

ModCreativeTabs.java - добавление в существующую вкладку

Пойдём по порядку:

@EventBusSubscriber

Аннотация класса

Это подписка на шину событий всего класса. Вся игра построена на тех или иных ивентах (запросах), данная аннотация позволяет автоматически "прослушивать" их, чтобы с ними взаимодействовать.

@SubscribeEvent

Это аннотация метода для обработки этих самых ивентов.

Логика добавления

Метод добавления предметов

В метод мы передаём тип события, в нашем случае работа с креативной вкладкой. Далее, если переводить на русский: "Если ключ вкладки является Ингредиенты, то добавляем в неё такой-то предмет".

Таких проверок мы можем указать сразу несколько для разных вкладок:

✅ Важно: Благодаря первой аннотации нам не нужно нигде регистрировать наш класс, всё произойдёт автоматически!

Вариант 2: Создание своей вкладки

Далее, второй вариант работы, куда интереснее - создание своей вкладки:

ModCreativeTabs.java - своя вкладка

Он схож с созданием предметов или блоков. Сначала создаём список для регистраций, в следующем методе создаём, настраиваем её и добавляем свои предметы, после этого создаём метод регистрации, который в дальнейшем вызовем в главном классе.

Чуть подробнее по настройке:

  • "learning_tab", () -> CreativeModeTab.builder() - регистрация и ID вкладки
  • .title(Component.translatable("itemGroup.learning_mod")) - имя вкладки для локализации (в файле .lang по этому пути можно добавить своё название)
  • .icon(() -> ModItems.RUBY.get().getDefaultInstance()) - заглавная иконка вкладки
  • .displayItems((parameters, output) -> {output.accept(ModItems.RUBY.get());}) - сами предметы во вкладке, перечислением можем добавить и больше
